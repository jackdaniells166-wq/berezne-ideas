# Стіна ідей Березнівської громади

Веб-платформа для збору й обговорення ідей мешканців громади: кожен може
запропонувати ідею, проголосувати за чужу, а адміністратор — розглянути
пропозиції та змінити їхній статус.

**Стек:** Node.js, Express, MongoDB Atlas (хмарна база даних).

## Можливості

- Публікація ідеї з категорією, описом і контактом для звʼязку
- Голосування «за» (1 голос з пристрою, захист через cookie + серверну перевірку)
- Перегляд, фільтр за категорією
- Категорії: Екологія, Інфраструктура, Культура, Освіта, Інше
- Статуси ідеї: нова → на розгляді → прийнято
- Адмін-панель: вхід за логіном/паролем, перегляд контактів авторів,
  зміна статусу ідеї, видалення спаму
- Контакти авторів приховані від усіх, крім адміністратора
- Адаптивна верстка (десктоп і мобільні пристрої)

## Структура проєкту

```
berezne-ideas/
├── server.js          # Express-сервер і всі API-маршрути
├── db.js              # підключення до MongoDB Atlas
├── package.json
├── render.yaml        # конфігурація автодеплою на Render
├── .env.example       # шаблон змінних середовища
└── public/
    ├── index.html      # фронтенд (сайт)
    └── images/logo.png
```

## Локальний запуск

1. Node.js 18+.
2. Встановити залежності:
   ```bash
   npm install
   ```
3. Створити безкоштовний кластер MongoDB Atlas (тариф M0) і скопіювати
   рядок підключення.
4. Скопіювати шаблон і заповнити власні значення:
   ```bash
   cp .env.example .env
   ```
5. Запустити:
   ```bash
   npm start
   ```
6. Відкрити http://localhost:3000

## Деплой

Проєкт готовий до деплою на [Render](https://render.com) через **Blueprint**
(`render.yaml` вже описує сервіс і змінні середовища). База даних —
зовнішня (MongoDB Atlas), тому підходить і безкоштовний план Render без
постійного диска.

## API

| Метод | Шлях | Опис | Доступ |
|---|---|---|---|
| GET | `/api/ideas` | список ідей | публічний |
| POST | `/api/ideas` | створити ідею | публічний |
| POST | `/api/ideas/:id/vote` | проголосувати / скасувати голос | публічний |
| POST | `/api/admin/login` | вхід адміністратора | публічний |
| GET | `/api/admin/me` | перевірка токена | публічний |
| PATCH | `/api/ideas/:id` | змінити статус ідеї | адмін |
| DELETE | `/api/ideas/:id` | видалити ідею | адмін |

## Безпека

- Паролі й секрети — тільки у змінних середовища, не в коді.
- Контакти авторів ідей не потрапляють у публічну відповідь API.
- Порівняння логіна/пароля через `crypto.timingSafeEqual` (захист від timing-атак).
- Rate limiting: до 5 нових ідей/хв та до 20 спроб входу/15 хв з однієї IP.
- Авторизація адміна — JWT-токен з терміном дії 12 годин.
