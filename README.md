# Стіна ідей Березнівської громади

Повноцінний сайт: **Node.js + Express + MongoDB Atlas**. Дані зберігаються централізовано в хмарній базі (не на диску Render — безкоштовний план Render не підтримує постійні диски), контакти авторів бачить лише адміністратор.

## Можливості
- Публікація ідей із категорією, описом і контактом для звʼязку
- Голосування (захист від накрутки — 1 голос на пристрій)
- Пошук, фільтр за категорією, сортування
- Вхід для адміна (логін/пароль → токен)
- **Контакти авторів бачить тільки адмін** (захищено на рівні сервера)
- Адмін може змінювати статус ідеї та видаляти спам
- Адаптивний дизайн (ПК і смартфон)

## Структура
```
berezne-ideas/
├── server.js          # сервер + API
├── db.js              # підключення до MongoDB
├── package.json
├── render.yaml        # конфіг для деплою на Render
├── .env.example       # приклад налаштувань
└── public/
    └── index.html     # сайт (фронтенд)
```

## Локальний запуск
1. Встановіть Node.js 18+.
2. У теці проєкту виконайте:
   ```bash
   npm install
   ```
3. Створіть безкоштовний кластер на https://www.mongodb.com/cloud/atlas (тариф M0, живе вічно, без картки), і скопіюйте рядок підключення (Database → Connect → Drivers).
4. Скопіюйте налаштування та змініть значення:
   ```bash
   cp .env.example .env
   ```
   Відкрийте `.env` і задайте свій `MONGODB_URI`, `ADMIN_LOGIN`, `ADMIN_PASSWORD` та `JWT_SECRET`.
5. Запустіть:
   ```bash
   npm start
   ```
6. Відкрийте у браузері: http://localhost:3000

## Деплой на Render.com (безкоштовно)
1. Створіть акаунт на https://render.com і завантажте цей проєкт у репозиторій GitHub (репозиторій краще зробити приватним).
2. У Render натисніть **New + → Blueprint** і підключіть репозиторій.
   Render автоматично підхопить `render.yaml`.
3. У полях, які Render попросить заповнити, задайте:
   - `MONGODB_URI` — рядок підключення з MongoDB Atlas
   - `ADMIN_LOGIN` — ваш логін адміна
   - `ADMIN_PASSWORD` — надійний пароль (це НЕ пароль від бази даних)
   - `JWT_SECRET` — Render згенерує сам, нічого вводити не треба
4. Натисніть **Apply**. Через кілька хвилин сайт буде онлайн за адресою виду
   `https://berezne-ideas.onrender.com`.
5. У логах деплою маєте побачити рядки:
   ```
   Підключено до MongoDB: berezne
   Сервер запущено на порту ...
   ```
   Якщо замість цього бачите `Відсутня обов'язкова змінна середовища` — якесь
   поле з кроку 3 лишилось порожнім. Якщо бачите помилку підключення — звірте
   рядок `MONGODB_URI` і те, що в Atlas дозволено підключення з будь-якої IP
   (Network Access → Add IP Address → Allow Access from Anywhere), бо Render
   не має статичної адреси на безкоштовному плані.

> База даних тепер живе в MongoDB Atlas, а не на диску Render — тому вона
> не зникає між деплоями і не потребує платного плану Render для збереження даних.

## API (коротко)
| Метод | Шлях | Опис |
|------|------|------|
| GET | `/api/ideas` | список ідей (контакти — лише адмін) |
| POST | `/api/ideas` | створити ідею |
| POST | `/api/ideas/:id/vote` | проголосувати (toggle) |
| POST | `/api/admin/login` | вхід адміна → токен |
| GET | `/api/admin/me` | перевірка токена |
| PATCH | `/api/ideas/:id` | змінити статус (адмін) |
| DELETE | `/api/ideas/:id` | видалити ідею (адмін) |

## Безпека
- Пароль і секрет зберігаються у змінних середовища, а не в коді.
- Контакти ніколи не потрапляють у публічну відповідь API.
- Є обмеження частоти запитів (rate limiting) на створення ідей і вхід.
