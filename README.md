# Стіна ідей Березнівської громади

Повноцінний сайт: **Node.js + Express + SQLite**. Дані зберігаються централізовано на сервері, контакти авторів бачить лише адміністратор.

## Можливості
- Публікація ідей із категорією, описом і контактом для звʼязку
- Голосування (захист від накрутки — 1 голос на пристрій)
- Пошук, фільтр за категорією, сортування
- Вхід для адміна (логін/пароль → токен)
- **Контакти авторів бачить тільки адмін** (захищено на рівні сервера)
- Адмін може змінювати статус ідеї та видаляти спам
- Адаптивний дизайн (ПК і смартфон)

## Структура
```
berezne-ideas/
├── server.js          # сервер + API
├── db.js              # база даних SQLite
├── package.json
├── render.yaml        # конфіг для деплою на Render
├── .env.example       # приклад налаштувань
└── public/
    └── index.html     # сайт (фронтенд)
```

## Локальний запуск
1. Встановіть Node.js 18+.
2. У теці проєкту виконайте:
   ```bash
   npm install
   ```
3. Скопіюйте налаштування та змініть логін/пароль:
   ```bash
   cp .env.example .env
   ```
   Відкрийте `.env` і задайте свій `ADMIN_LOGIN`, `ADMIN_PASSWORD` та `JWT_SECRET`.
4. Запустіть:
   ```bash
   npm start
   ```
5. Відкрийте у браузері: http://localhost:3000

## Деплой на Render.com (безкоштовно)
1. Створіть акаунт на https://render.com і завантажте цей проєкт у репозиторій GitHub.
2. У Render натисніть **New → Web Service** і підключіть репозиторій.
   Render автоматично підхопить `render.yaml`.
3. У розділі **Environment** задайте:
   - `ADMIN_LOGIN` — ваш логін адміна
   - `ADMIN_PASSWORD` — надійний пароль
   - `JWT_SECRET` — згенерується автоматично (або задайте свій)
4. Натисніть **Deploy**. Через кілька хвилин сайт буде онлайн за адресою виду
   `https://berezne-ideas.onrender.com`.

> Важливо: у `render.yaml` уже налаштовано постійний диск `/var/data`,
> тому база даних НЕ зникатиме між деплоями.

## API (коротко)
| Метод | Шлях | Опис |
|------|------|------|
| GET | `/api/ideas` | список ідей (контакти — лише адмін) |
| POST | `/api/ideas` | створити ідею |
| POST | `/api/ideas/:id/vote` | проголосувати (toggle) |
| POST | `/api/admin/login` | вхід адміна → токен |
| GET | `/api/admin/me` | перевірка токена |
| PATCH | `/api/ideas/:id` | змінити статус (адмін) |
| DELETE | `/api/ideas/:id` | видалити ідею (адмін) |

## Безпека
- Пароль і секрет зберігаються у змінних середовища, а не в коді.
- Контакти ніколи не потрапляють у публічну відповідь API.
- Є обмеження частоти запитів (rate limiting) на створення ідей і вхід.
